# Frontend Application (FE-001 through FE-004)

Worker Voice Application & Supervisor Dashboard built with React, Vite, and TypeScript.

## How to Run Locally

1. Install dependencies:
   ```bash
   cd frontend
   npm install
   ```

2. Start development server:
   `npm run dev`

3. Build production bundle:
   `npm run build`

## Routes
- `/worker` or `/` : Field Worker hands-free voice spine & text fallback view
- `/inbox` : Supervisor Review Inbox for near-miss reports
- `/patterns` : Hazard Pattern signals & recurrent near-miss analysis
- `/maintenance` : Logged maintenance entries
